# Magic Slug

Metal Slug-style pixel-art game with magic instead of guns. Godot 4.3+ project in `game/`, art generated by Node scripts
in `tools/art/` using the pixelfx submodule (`tools/pixelfx`). The owner plays on a MacBook M1 with a PS5 controller and
writes in Portuguese (reply in Portuguese; in-game text is Portuguese without accents for the pixel font).

Read `NOTES.md` before changing anything: it maps every kind of change to the one file to edit, so you rarely need
to read the whole codebase. Most changes are JSON edits in `game/data/`.

After a change: run `godot --headless --path game res://tests/smoke.tscn` if Godot is available, update `CHANGELOG.md`,
and keep `NOTES.md` accurate if you add files or systems. If `tools/pixelfx` is empty, run `git submodule update --init`.
